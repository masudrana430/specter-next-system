# Feature Map

## Navigation
- Header: Services, Portfolio, Pricing, About Us, Careers, Start a Project
- Footer: Company links, 13 service links, newsletter, Terms, Privacy, Security
- Mobile menu included

## Interactive modules
- Sticky header
- Mobile navigation
- Stats counter
- Newsletter state
- Before/after category comparison
- FAQ accordion
- Services scene/progress navigation
- Pricing service filter + URL hash
- Expandable pricing features
- Careers sector selector + CV validation
- Project package selector
- Custom scope builder
- Country/dial/timezone selection
- Multi-image project references
- Success/reset states

## Server endpoints
- `/api/newsletter`
- `/api/careers`
- `/api/project-inquiries`

## Data modules
- `src/data/site.ts`: navigation, services, industries, portfolio, testimonials, values
- `src/data/pricing.ts`: packages and service-pricing structure
- `src/data/countries.ts`: country, dial code, timezone data
